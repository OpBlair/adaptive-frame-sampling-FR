# Adaptive Frame Sampling Optimization in Continuous Attendance monitoring for Efficient Attendance Monitoring

## Background

Fixed-point attendance systems verify attendance at a single point in time and do not confirm if that person stayed for the entire session. Continuous facial recognition for attendance offers a solution, but processing every frame from the camera increases compute resource usage since not all frames are required for recognition.

This research proposes a system that performs **adaptive frame sampling** to minimize resource usage while maintaining a high attendance score and recognition accuracy.
